Добавление услуги в бронирование:

POST /api/v1/bookings/1/extras
Content-Type: application/json

{
    "extraServiceId": 7,
    "quantity": 2,
    "pricePerUnit": 500.00,
    "totalPrice": 1000.00
}
Получение всех услуг в бронировании:

GET /api/v1/bookings/1/extras
Получение общей суммы услуг:

GET /api/v1/bookings/1/extras/total
Обновление услуги:

PATCH /api/v1/bookings/1/extras/1
Content-Type: application/json

{
    "quantity": 3,
    "pricePerUnit": 450.00,
    "totalPrice": 1350.00
}
Удаление услуги:

DELETE /api/v1/bookings/1/extras/1
