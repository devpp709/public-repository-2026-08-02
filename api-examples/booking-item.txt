2. Работа с BookingItem через API
Получение всех автомобилей в бронировании

GET /api/v1/bookings/1/items
Добавление автомобиля в существующее бронирование

POST /api/v1/bookings/1/items
Content-Type: application/json

{
    "carId": 8,
    "dailyRate": 4200.00,
    "hourlyRate": null,
    "totalPrice": 8400.00
}
Обновление автомобиля в бронировании (изменение цены)

PATCH /api/v1/bookings/1/items/1
Content-Type: application/json

{
    "dailyRate": 3200.00,
    "totalPrice": 9600.00
}
Удаление автомобиля из бронирования

DELETE /api/v1/bookings/1/items/2
Удаление всех автомобилей из бронирования

DELETE /api/v1/bookings/1/items
3. Поиск и фильтрация
Поиск бронирований по автомобилю

GET /api/v1/bookings/search?car_id=6
Получение истории аренды автомобиля

GET /api/v1/cars/6/bookings

Статистика по BookingItem
bash
GET /api/v1/bookings/items/popular?limit=5
